================================================================================
🐛 COMMON ISSUES & FIXES
================================================================================

Issue: "Cannot connect to MySQL"
  Fix: Update password in application.properties

Issue: "Port 3000 already in use"
  Fix: Edit frontend/vite.config.ts, change port to 3001

Issue: "npm install fails"
  Fix: Run "npm cache clean --force" then "npm install"

Issue: "Spring Boot won't start"
  Fix: Make sure MySQL is running and database exists
